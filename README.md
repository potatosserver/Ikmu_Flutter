# Ikmu_Flutter

A Flutter application for KMU (高雄醫學大學) mobile query system.

## Features

- IRS 答題系統（問卷列表與答題）
- 行事曆、課表、成績查詢
- 場地查詢
- 新聞、校園資訊
- Windows/Linux 桌面版建置

## Getting Started

This project is a starting point for a Flutter application.

- [Lab: Write your first Flutter app](https://docs.flutter.dev/get-started/codelab)

## Build

```bash
flutter pub get
flutter analyze
flutter build windows --release   # Windows host only
flutter build linux --release     # Linux host
```
